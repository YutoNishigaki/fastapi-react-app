# FastAPI React App

このプロジェクトは、FastAPI、Nextjs、および PostgreSQL を使用したフルスタックアプリケーションです。

Docker を使用して、開発環境を簡単に構築できます。

## 構成

- **backend**: FastAPI を使用したバックエンドアプリケーション
- **frontend**: Nextjs を使用したフロントエンドアプリケーション
- **docker-compose.yml**: Docker コンテナの設定ファイル

## セットアップ

1. リポジトリをクローンします。
2. `docker-compose up` を実行して、すべてのサービスを起動します。
3. ブラウザで `http://localhost:3000` にアクセスして、アプリケーションを確認します。

## 使用技術

- **FastAPI**: 高速な Python ウェブフレームワーク
- **Nextjs**: ユーザーインターフェースを構築するための JavaScript ライブラリ
- **PostgreSQL**: リレーショナルデータベース
- **Docker**: コンテナ化されたアプリケーションの管理

## アーキテクチャ

### ディレクトリ構成

| 名称         | 区分         | 役割                                        |
| ------------ | ------------ | ------------------------------------------- |
| main.py      | ファイル     | エントリーファイル                          |
| core         | ディレクトリ | 共通する設定やロジック                      |
| api          | ディレクトリ | ルーティング                                |
| models       | ディレクトリ | ORM とモデル定義                            |
| schemas      | ディレクトリ | Pydantic でリクエスト・レスポンスモデル定義 |
| repositories | ディレクトリ | DB の CRUD 操作                             |
| services     | ディレクトリ | ビジネスロジック                            |
| db           | ディレクトリ | DB 接続設定                                 |
| tests        | ディレクトリ | テストコード                                |

### レイヤーと依存

| レイヤー      | 責務                         | 依存方向 |
| ------------- | ---------------------------- | -------- |
| API 層        | ルーティング、リクエスト処理 | ↓        |
| Service 層    | ビジネスロジック             | ↓        |
| Repository 層 | データアクセス               | ↓        |
| Model 層      | ORM 構造定義                 | —        |
